How to Play

Guess the secret 5-card poker hand in 6 tries.

The hand type (e.g., "Two Pair", "Flush") is shown as a hint. Use your poker knowledge to narrow it down!

Both hands are sorted ascending by rank. Each card slot is compared directly:

  • Green — Exact match: right rank and suit in this slot
  • Orange — This exact card is in the hand but in a different slot
  • Yellow — Rank matches this slot but suit is wrong
  • Blue — Suit matches this slot but rank is wrong
  • Gray — Neither rank nor suit matches this slot

Smart sorting: When you guess cards of the same rank (pairs, trips), the game automatically arranges them to best match the secret hand. If you have the right cards, they'll align.

Winning: Get all 5 cards correct. If same-rank cards are just swapped, it still counts as a win!

Strategy tips:

  • The hand type tells you the structure — use it!
  • Green = locked in, perfect
  • Orange = you have this card, it belongs in another slot
  • Yellow = right rank, try different suits
  • Blue = right suit, try different ranks

Keyboard shortcuts:

  • 2-9, J, Q, K, A — Select rank
  • 1 — Select rank 10
  • S, H, D, C — Select suit (after rank)
  • Enter — Submit guess
  • Backspace — Remove last card
  • Escape — Clear current guess
